# BAT and GUI Application

`IDF_Geometry_GUI` contains the end-user interface and Windows launcher. `Restoration_Engine` contains the command-line engine and 13-zone reference model loaded by the GUI.

Start the application with:

```text
IDF_Geometry_GUI/Launch_IDF_Geometry_GUI.bat
```

The directories must remain siblings unless the path constants in `idf_gui_postprocessor.py` and `manual_restore_wizard.py` are updated.

See `IDF_Geometry_GUI/GUI_User_Guide.md` for operation details.
