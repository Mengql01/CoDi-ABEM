# Archetype Case Generator

`archetype_idf.py` produces representative L-, T-, U-, H-, cross-, courtyard/atrium-, and cut/trapezoid-type cases from the four compact input tasks.

Use the optional `--report` argument to create a JSON validation report for a generated case. The report includes generation mode, source and output paths, operation parameters, zone count, surface count, window count, merge count, and dropped-window count.

Task-08 roof cases are generated by the separate `Roof_Lifting` tool. Generated IDFs are published under `02_Eight_Complex_Building_Case_Results`, outside this source-code directory.
